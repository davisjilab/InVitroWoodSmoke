This folder contains the script used for evaluating rhesus macaque-to-human gene orthology and genomic interval conservation. The number at the beginning of the script name indicates the order in which it was run. Orthology input CSV files, `rhesus_intervals.csv`, and `rheMac10ToHg38.over.chain.gz` are required data files for running `4_Rhesus_Human_conservation_analysis.R` when both analysis modes are enabled.
