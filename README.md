# InVitroWoodSmoke

This repository contains code used for analyses accompanying the in vitro wood-smoke exposure manuscript from the Ji Lab at the University of California, Davis.

The `scripts/` folder contains analysis scripts. Each analysis folder contains a README listing the required input data.

## Repository structure

```text
InVitroWoodSmoke/
├── README.md
└─ scripts/
    ├── README.md
    ├── WGCNA/
    │   ├── README.md
    │   └── Wood_Smoke_WGCNA_analysis.R
    ├── Methylation_Expression_Correlation/
    │   ├── README.md
    │   └── Methylation_Expression_correlation.R
    ├── Transcriptome_Similarity/
    │   ├── README.md
    │   └── Transcriptome_similarity_analysis.R
    └── Rhesus_Human_Conservation/
        ├── README.md
        └── Rhesus_Human_conservation_analysis.R
```
